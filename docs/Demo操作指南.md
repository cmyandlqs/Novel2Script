# Demo 操作指南

本文说明如何复现 Noverl2Script 的完整演示流程。

## 前置条件

- Node.js 18+
- 已运行 `npm install`

## 启动

```bash
npm run dev
```

浏览器访问 `http://localhost:3000`。

## Demo 流程

### 步骤 1：加载或粘贴小说文本

页面默认已加载原创三章节小说样例《雨夜档案》。也可以在左侧输入区粘贴其他 3+ 章节的小说文本。

支持的章节格式：
- `第1章 标题` / `第一章 标题`
- `Chapter 1 Title`
- `## 第一章 标题`（Markdown 标题）

### 步骤 2：确认章节解析

中间面板顶部显示校验状态。识别到 3+ 章节时显示绿色"满足 3+ 章节输入要求"，下方列出每章标题和字数。

### 步骤 3：生成剧本初稿

点击右上角"生成初稿"按钮。中间面板显示 Pipeline 6 个步骤的执行状态：

1. 章节摘要
2. 人物抽取
3. 地点抽取
4. 剧情梗概
5. 场景拆分
6. 改编说明

完成后中间面板展示人物表（名称、角色定位、描述）和场景列表（标题、时间段、摘要、beat 列表）。

### 步骤 4：查看校验结果和评分

右侧面板下方自动展示：

- **校验结果**：YAML 解析和 Schema 校验通过/失败状态。
- **质量评分**：总分和 5 个维度（赛题合规性、结构完整度、可编辑性、引用一致性、章节覆盖度）。

### 步骤 5：编辑剧本

中间面板的人物和场景卡片可直接编辑：

- 修改人物名称或描述。
- 修改场景标题、时间段或摘要。
- 修改 beat 内容（动作、对白、旁白、转场）。

编辑后右侧 YAML 输出实时同步更新。

### 步骤 6：重新校验并导出

- 点击右侧面板的刷新按钮重新校验编辑后的 YAML。
- 点击复制按钮将 YAML 复制到剪贴板。
- 点击下载按钮导出 `.yaml` 文件。

## Mock 模式

默认使用 MockProvider，无需 API Key 即可完整运行上述流程。Mock Provider 返回固定样例数据。

## 真实 LLM 模式

配置环境变量后可切换为真实模型生成：

```bash
cp .env.example .env
# 编辑 .env 填入 OPENAI_API_KEY
```

支持 OpenAI 兼容 API（DeepSeek、GLM 等），通过 `OPENAI_BASE_URL` 配置。

## 自动化验证

```bash
npm test          # 24 个测试全部通过（含 Demo 示例校验和评分）
npm run typecheck # TypeScript 类型检查
npm run lint      # ESLint 检查
npm run build     # 生产构建
```

示例输出评分在自动化测试中验证不低于 85 分。
